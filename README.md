# personal-portfolio-project

## 📌 Project Overview

This project is a responsive personal portfolio website built using HTML and CSS. The goal of this website is to showcase my skills, projects, and interests as a frontend developer in training while demonstrating clean structure, modern layout techniques, and mobile-friendly design.
The website is designed to be clear, organized, and visually appealing on both desktop and mobile devices.

## 🎯 Project Goals

Create a clean and organized multi-section webpage
Practice semantic HTML structure
Use modern CSS layout techniques (Flexbox & Grid)
Ensure the site is fully responsive and mobile-friendly
Apply consistent styling with a royal blue, black, and white color theme
Improve accessibility and readability

## Responsive Design

This website was built using a mobile-first approach:
Content stacks vertically on smaller screens for easy scrolling
Navigation adapts for mobile screens
Text sizes and spacing adjust at different screen widths
Project cards change layout using CSS Grid at larger breakpoints

## 🎨 Design Choices

Color Theme: Royal blue, black, and white for a professional and modern look
Gradient Text: Used in the hero section to add visual interest
Cards: Project and skill cards create clear visual separation
Typography: Simple, readable fonts for clarity and accessibility
